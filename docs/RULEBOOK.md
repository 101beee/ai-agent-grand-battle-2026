## 목적과 구성

텍스트로 주어진 목표에 답하거나 작업을 수행하는 AI Agent 시스템을 개발합니다. 처음 보는 상황과 불확실한 상황에서 판단하고 필요한 도구를 사용하는 능력을 평가합니다. 포스터 기준 7팀이 참가합니다. Final Project 안내의 팀 구성은 3명 팀 2개, 4명 팀 5개입니다.

## 적용 자료

이 룰북은 제공된 Final Project PDF와 사용자 전달 공지·추가 규칙을 대회 안내로 정리한 것입니다. 실습 PDF는 코드 설명의 근거이며, 다른 연도 참고 저장소의 규정을 이 대회에 적용하지 않습니다. 충돌하는 부분은 최신 공지와 추가로 전달된 제한을 반영했습니다. 후속 운영진 공지가 있으면 갱신합니다.

## 허용 모델과 금지 사항

### 로컬 모델

- 모든 추론은 로컬 모델로 수행합니다. 제공 서버에서 로컬로 구동하는 LLM을 API로 호출하는 것은 여기에 포함됩니다.
- ChatGPT·Claude·Gemini 등 온라인 모델 API는 사용할 수 없습니다.
- 웹 검색을 통해 Gemini 등 외부 AI가 생성한 답변을 가져오는 방식도 허용하지 않습니다. 다른 도구나 MCP 서버에 온라인 모델을 붙여 우회하지 않습니다.
- 일반 웹 원문 검색·조회는 강의와 예시 미션에서 사용하는 방식입니다. 검색 엔진의 AI 요약·생성 답변을 Agent의 답변 근거로 가져오는 방식은 사용하지 마세요.

### 모델 규모

| 구분 | 기준 |
|---|---|
| 공통 제공 모델 | 공지에 적힌 **Qwen3.8-27B** 사용 가능 |
| 더 큰 모델 | 사용 불가 |
| 대체 모델 | 27B 미만 모델 사용. 출시 시점은 무관 |
| 다른 27B 모델 | 공지 문구 경계가 불명확하므로 사용 전 운영진 확인 |
| MoE | 괄호 안 active 수치가 아니라 **전체 파라미터 수**로 판정 |

공지에는 “이보다 파라미터 사이즈가 큰 모델(27B 이상)”이 함께 적혀 있습니다. 제공 27B 모델을 금지한다고 해석하지 않았으며, 다른 27B 모델을 자동 허용하지도 않았습니다. **정확히 27B인 대체 모델의 허용 여부는 미확정**입니다. 모델 표기는 공지를 그대로 옮긴 것으로, 실제 API 모델 ID는 eTL/운영진 안내에서 확인합니다.

예: `MiniMax-M3 427B (23B active)`는 **427B** 기준으로 사용 불가입니다. 공지의 15B 모델 예시는 제공 모델보다 나중에 출시되었어도 크기 제한 안이면 사용할 수 있다는 뜻입니다.

### 데이터와 RAG

- **로컬 데이터 사용 금지.**
- **RAG 사용 금지.**
- 기존 공지의 학습·RAG 데이터 제출 및 공유 안내를 현재 허용 예외로 적용하지 않습니다.
- 기존 공지는 모든 사용 데이터를 11월 20일까지 문의 메일로 제출하고, 미제출 데이터는 실전에서 사용할 수 없으며, 11월 21일 eTL 공개를 예고했습니다. 이는 [공지 이력](ANNOUNCEMENTS.md)에 남깁니다. 실제 공개 완료 여부는 제공 자료만으로 확인되지 않습니다.
- 평가 문제에서 제공하는 파일을 입력으로 처리하는 것과 참가팀이 미리 보유한 로컬 지식·데이터를 사용하는 것은 구분할 필요가 있습니다. 예시에는 제공 Excel·사진이 있으나, 구체적인 허용 경계는 아직 전달되지 않았으므로 운영진 확인이 필요합니다.

## 미션과 평가

1. 각 팀은 자신의 시스템이 풀 수 있으면서 다른 팀에게는 어려울 것으로 예상되는 문제 **1개**를 제출합니다.
2. 팀별로 모은 문제와 히든 미션으로 평가합니다. 공지 기준 TA 출제 문제는 **상·중·하 각 1개**입니다.
3. **가장 많은 문제를 해결한 팀이 우승**합니다.
4. 해결 문제 수가 같으면 **더 빨리 수행한 팀이 우승**합니다.
5. 실제 미션은 **11월 30일(월)까지 연구실 방문**으로 수행합니다. TA가 제출 코드를 사전 설치하고 실행하며 환경설정 맞춤이 허용됩니다.

문제별 부분점수, 시간 합산 방식·측정 구간, 제한 시간, 실패·재시도, 동률 시간 처리, 위반 시 제재 방식은 자료에 없습니다. 이 저장소는 이를 새 규정으로 만들지 않습니다. 리더보드는 운영진이 확정한 해결 수와 수행 시간을 입력하는 결과 공개 양식입니다.

| 항목 | 안내 |
|---|---|
| 코드 제출 | 2026년 11월 25일(수) “자정” (PDF 원문) |

| 결과 발표 | 2026년 12월 2일(수) 오후 2시, 220동 201호 (포스터) |
| 발표 시간 | 팀당 10분, 자신의 AI Agent를 어떻게 만들었는지 설명 |

“11월 25일 자정”의 정확한 시각은 시작/종료 경계가 모호하므로 원문을 유지합니다. 제출 마감 타임스탬프와 제출 경로는 eTL/운영진 공지에서 확인하세요. 연구실 방문 장소는 포스터의 발표 장소와 같다고 가정하지 않습니다.

## 운영진 확인이 필요한 항목

- 정확히 27B인 대체 모델의 허용 여부
- 평가 문제로 제공되는 파일의 입력 범위와 로컬 데이터 금지의 세부 경계
- 코드 마감의 정확한 시각, 제출 위치, 문의 메일, 미션 수행 연구실 위치
- 수행 시간 측정·합산 방식, 재시도·제한 시간 등 세부 채점 방식
- 제공 서버의 프로토콜, base URL, 정확한 모델 ID (키는 eTL 8주차 자료)
