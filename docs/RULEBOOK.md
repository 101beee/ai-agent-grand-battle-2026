# Competition Rules

## 1. Objective

Develop an AI agent that understands a text request and uses tools to answer it or complete the requested actions. Seven teams participate in the competition.

## 2. Models

- All inference must use local models. Teams may call the local LLM API hosted on the provided server.
- Online model APIs such as ChatGPT, Claude, and Gemini are prohibited.
- The shared model is Qwen3.8-27B. Models larger than the shared model are prohibited.
- There is no restriction on release date. Smaller models, such as a 15B model, may be used even if released later.
- For MoE models, size is determined by total parameters. For example, `427B (23B active)` counts as a 427B model and is prohibited.

## 3. Data and External Services

- Local data is prohibited.
- RAG is prohibited.
- Agents may search for and retrieve information from regular webpages.
- Retrieving answers generated by an external AI, such as Gemini, through search or another service is prohibited.
- The online model restriction also applies to models accessed through an MCP server or another tool.

## 4. Missions

- Each team submits one problem that its own system can solve and that is expected to be difficult for other teams.
- Evaluation uses the collected team problems and hidden missions.
- The organizers provide one problem at each difficulty level: high, medium, and low.

### Example Problems

1. Calculate total transportation expenses for September 2026 from the supplied Excel ledger.
2. Send the message “미션 수행합니다.” to a specified email address at 2:00 PM KST.
3. Identify the museum in a photo and calculate admission for celebrity A, their spouse, and their children visiting on October 25.

## 5. Ranking

1. The team that solves the most problems wins.
2. If teams solve the same number of problems, the team with the shorter execution time wins.

## 6. Submission and Execution

- Submit the team's code by midnight on Wednesday, November 25, 2026.
- Complete the mission session by visiting the laboratory by Monday, November 30, 2026.
- The organizers install the submitted code before execution. Configuration changes needed to match the execution environment are permitted.

## 7. Final Presentations

- Date: Wednesday, December 2, 2026, 2:00 PM KST
- Location: Building 220, Room 201
- Duration: 10 minutes per team
- Content: Agent design, tool configuration, and problem-solving approach
