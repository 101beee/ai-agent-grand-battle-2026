# 대회 규정

## 1. 목표

텍스트로 주어진 요청을 이해하고 필요한 도구를 사용해 답변하거나 작업을 완료하는 AI Agent를 개발합니다. 참가팀은 총 7팀입니다.

## 2. 모델

- 모든 추론은 로컬 모델로 수행해야 합니다. 제공 서버에서 실행하는 로컬 LLM API를 사용할 수 있습니다.
- ChatGPT, Claude, Gemini 등 온라인 모델의 API는 사용할 수 없습니다.
- 공통 제공 모델은 Qwen3.8-27B이며, 이보다 큰 모델은 사용할 수 없습니다.
- 모델의 출시 시점은 제한하지 않습니다. 제공 모델보다 작은 15B 모델 등은 사용할 수 있습니다.
- MoE 모델은 전체 파라미터 수를 기준으로 판단합니다. 예를 들어 `427B (23B active)`는 427B 모델이므로 사용할 수 없습니다.

## 3. 데이터와 외부 서비스

- 로컬 데이터는 사용할 수 없습니다.
- RAG는 사용할 수 없습니다.
- 일반 웹페이지의 정보를 검색하고 조회할 수 있습니다.
- 검색이나 다른 서비스를 통해 Gemini 등 외부 AI가 생성한 답변을 가져오는 방식은 사용할 수 없습니다.
- MCP 서버나 다른 도구를 경유하더라도 온라인 모델 사용 제한은 동일하게 적용됩니다.

## 4. 미션

- 각 팀은 자신의 시스템이 해결할 수 있으면서 다른 팀에는 어려울 것으로 예상되는 문제 하나를 제출합니다.
- 팀별 제출 문제와 히든 미션을 포함한 문제셋으로 평가합니다.
- 운영진은 상, 중, 하 난이도의 문제를 하나씩 출제합니다.

### 예시 문제

1. 제공된 가계부 Excel에서 2026년 9월의 교통비 총액을 계산합니다.
2. 한국시간 오후 2시에 지정된 주소로 “미션 수행합니다.”라는 메일을 보냅니다.
3. 사진 속 박물관에 연예인 A씨가 10월 25일 배우자 및 자녀와 함께 방문할 때의 입장료를 계산합니다.

## 5. 평가

1. 해결한 문제 수가 많은 팀이 우승합니다.
2. 해결한 문제 수가 같으면 수행 시간이 짧은 팀이 우승합니다.

## 6. 제출과 실행

- 팀별 코드는 2026년 11월 25일 수요일 자정까지 제출합니다.
- 실제 미션은 2026년 11월 30일 월요일까지 연구실을 방문하여 수행합니다.
- 운영진이 제출 코드를 사전 설치한 뒤 실행합니다. 실행 환경을 맞추기 위한 설정 변경은 허용됩니다.
