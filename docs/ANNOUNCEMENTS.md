# 공지

정리 기준: 2026-11-24. 아래는 사용자가 전달한 공지의 요약입니다. 개별 공지 게시일은 별도로 제공되지 않았습니다. 로그인 정보와 서버 키는 포함하지 않습니다.

## 현재 적용되는 제한

| 항목 | 내용 |
|---|---|
| 온라인 모델 | ChatGPT·Claude 등 온라인 모델 API 금지, 전부 로컬 모델 사용 |
| 공통 모델 | 공지 표기 `Qwen3.8-27B` |
| 모델 크기 | 제공 모델보다 큰 모델 불가. 공지에 “27B 이상” 문구도 있어 다른 27B 모델은 확인 필요 |
| 출시 시점 | 제한 크기 안이면 최신 모델도 가능 |
| MoE | 전체 파라미터 수 적용. `427B (23B active)`는 427B 기준으로 불가 |
| 로컬 데이터 | 교수님 오픈채팅방 공지에 따라 사용 자체 금지 |
| RAG | 추가 전달 규칙에 따라 사용 금지 |
| 외부 AI 우회 | 검색으로 Gemini 등 외부 AI가 답하게 하고 그 답을 가져오는 방식 금지 |

## 기존 데이터 제출 공지 기록

공정성을 위해 각 팀이 사용할 모든 데이터(학습·RAG 등)를 **11월 20일(금)까지** 문의 메일로 제출하도록 안내했습니다. 기한 내 제출하지 않은 데이터는 실전 사용 불가이며, 제출 데이터는 **11월 21일(토) eTL로 공개 예정**이라고 공지했습니다.

같이 전달된 후속 문구는 **로컬 데이터 사용 자체 금지**이고, 추가로 RAG 금지도 전달되었습니다. 따라서 과거 제출 사실만으로 현재 데이터 사용이 허용된다고 해석하지 않습니다. 공개 완료 여부와 실제 문의 메일 주소는 제공 자료에 없습니다.

## 제공 서버

조별 서버 local LLM API key는 **eTL 8주차 자료**에 업로드되었다고 공지했습니다. 공개 저장소에 키를 올리지 마세요. 서버의 실제 프로토콜·주소·모델 ID는 해당 자료에서 확인합니다.

## 예시 문제

TA 출제 3문제(상·중·하) 중 **중·하 수준**에 해당하는 예시이며, 실습시간에 진행한 예시도 참고 대상입니다.

1. 제공된 가계부 Excel 파일에서 2026년 9월 교통비 총액을 계산하라.
2. 한국시간 오후 2시에 `xxx@snu.ac.kr`로 “미션 수행합니다.”라는 메일을 보내라. 주소는 공지의 예시 자리표시자입니다.
3. 사진 속 박물관에 연예인 A씨가 10월 25일 가족(배우자와 자녀)과 방문할 때 입장료를 계산하라.

이 문서의 미션 문장은 대회를 설명하기 위한 예시이며, 저장소를 정리하는 과정에서 실제로 수행한 작업이 아닙니다.
