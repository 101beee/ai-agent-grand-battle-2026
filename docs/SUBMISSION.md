# Submission

## Code

Submit the team's code by midnight on Wednesday, November 25, 2026. Include the configuration needed to install and run the agent.

```text
Team name:
Team leader and members:
Python version and operating system:
Installation command:
Execution command:
Input format:
Model name and total parameter count:
Required environment variable names:
Connected tools:
Team problem:
```

Do not include authentication key values in the code.

## Team Problem

Each team submits one problem that its system can solve and that is expected to be difficult for other teams.

## Mission Session

Visit the laboratory and complete the mission session by Monday, November 30, 2026. The organizers install the submitted code before execution. Configuration changes needed to match the execution environment are permitted.

## Presentation

Each team gives a 10-minute presentation at 2:00 PM KST on Wednesday, December 2, 2026, in Building 220, Room 201. Explain the agent design, tool configuration, and problem-solving approach.
