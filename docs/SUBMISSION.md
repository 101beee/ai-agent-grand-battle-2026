## 재현을 위한 권장 동봉 정보

다음은 TA의 설치·실행을 돕기 위한 **권장 양식**이며 추가 채점 규정이 아닙니다.

```text
팀명:
팀장 및 팀원: (운영진 제출물에 기재)
Python / OS 버전:
설치 명령:
실행 명령과 입력 형식:
로컬 모델 이름 / 전체 파라미터 수 / MoE 여부:
필요한 환경변수 이름: (키 값 제외)
사용 도구와 필요한 계정/프로그램:
팀별 제출 문제:
```

비밀 키는 eTL 등 지정된 경로에서 별도로 설정합니다. 로컬 데이터·RAG 금지를 준수하고, 운영진 확인이 필요한 항목은 [룰북](RULEBOOK.md#운영진-확인이-필요한-항목)에 모았습니다.
