## 대회 후 갱신

1. 운영진이 검수한 팀별 최종 해결 문제 수와 수행 시간을 `results.csv`에 입력합니다. 시간 단위는 **초**입니다. 문제별 시간의 측정·합산 방식은 운영진이 먼저 확정해야 합니다.
2. 저장소 루트에서 `python scripts/update_leaderboard.py`를 실행합니다. README의 요약 표와 이 표가 함께 갱신됩니다.
3. `python scripts/update_leaderboard.py --check`로 동기화 상태를 확인한 뒤 변경을 커밋합니다.

CSV 열은 `team,solved,elapsed_seconds,presentation_url`입니다. 발표/시연 HTTPS URL은 공란으로 둘 수 있습니다. 현재 CSV에는 **헤더만** 있으며 가상 성적은 없습니다.

기본 정렬은 해결 문제 수 내림차순, 수행 시간 오름차순입니다. 해결 수와 시간이 모두 같으면 임의로 승자를 정하지 않고 같은 순위를 표시합니다. 이 공동 순위 표시는 새 대회 규정이 아닌 게시용 기본 동작이며, 운영진이 추가 동률 기준을 공지하면 스크립트를 수정합니다. 공란 행은 미입력 공간으로 순위가 아닙니다.

결과 공개 후에는 README와 이 문서의 “대회 전·결과 미공개” 문구도 실제 상태에 맞게 수정하세요. CSV 스크립트는 결과 표만 갱신합니다.
